# Apply Case Pattern

Choose one primary pattern from the task type. Do not mix patterns unless the teacher explicitly requests a hybrid.

## Routing

- Decision or choice → `references/decision-case.md`
- Diagnosis or root cause → `references/diagnostic-case.md`
- Analysis or explanation → `references/mechanism-analysis.md`
- Solution or intervention design → `references/solution-design.md`
- Conflicting duties or values → `references/ethical-dilemma.md`
- Role play or simulation → `references/role-simulation.md`

## Common Requirements

1. Establish a bounded context and a credible trigger event.
2. Give roles different information, responsibilities, and risks.
3. Introduce evidence that supports more than one defensible interpretation.
4. Escalate consequences before the final task.
5. Stop before resolving the learner's decision.

Reject structures that merely describe a topic, give the answer in advance, or use characters with interchangeable interests.
