# Mechanism Analysis Case

The learner must explain how and why an outcome emerged.

- Define a change over time rather than a static description.
- Include actors, incentives, constraints, and at least one feedback or interaction effect.
- Provide evidence supporting competing explanations.
- End with a request to construct and compare causal accounts and state what evidence would discriminate them.

Reject a case that asks for theory recall without applying it to evidence.
