# Role Simulation Case

The learner must act from a role with asymmetric information and constraints.

- Define each role's goal, authority, private information, and exposure to risk.
- Establish rules, time limit, resources, and a trigger event.
- Create negotiation dependencies so no role can succeed alone.
- End with a concrete interaction task and debrief questions separating role performance from conceptual learning.

Reject simulations where every role receives identical information or has no meaningful action.
