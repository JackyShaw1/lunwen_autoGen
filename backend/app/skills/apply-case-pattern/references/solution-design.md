# Solution Design Case

The learner must design an intervention under real constraints.

- State the desired outcome, baseline, resources, deadline, and non-negotiable constraints.
- Show why an earlier or intuitive solution is insufficient.
- Include stakeholder adoption, execution capacity, and measurement risks.
- Require a phased solution, responsibilities, milestones, indicators, and contingency plan.

Reject unconstrained brainstorming or a single tool presented as the answer.
