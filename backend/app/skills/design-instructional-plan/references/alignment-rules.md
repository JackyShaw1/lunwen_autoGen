# Alignment Rules

For every objective, provide:

- Case evidence: the exact section, role, event, datum, or decision used.
- Learning activity: what the learner does with that evidence.
- Assessment: what observable response demonstrates achievement.

Use stable IDs `LO1`, `LO2`, and so on. Every ID must appear in the alignment matrix. A generic “group discussion” is not an assessment; specify criteria such as evidence accuracy, causal completeness, option trade-off quality, or implementation feasibility.

Time plans must name minutes for reading, individual thinking, group work, whole-class discussion, and teacher synthesis. Their sum must not exceed `class_hours × 45` minutes unless the task explicitly defines another class-hour duration.
