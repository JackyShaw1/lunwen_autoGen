# Computing and Information Systems

- Roles: product owner, user, architect, developer, operations, security, data steward, or auditor.
- Evidence: requirements, architecture constraints, logs, latency, error rates, threat scenarios, incident timeline.
- Decision variables: reliability, security, privacy, maintainability, cost, performance, and delivery risk.
- Common failure: turn a technical trade-off into a generic department-conflict story without system evidence.
- Safety: avoid actionable exploit instructions, real credentials, or claims that a fictional control guarantees security.
