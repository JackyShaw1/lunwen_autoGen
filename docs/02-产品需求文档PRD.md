# CaseAutoGenSystem 产品需求文档（PRD）

> **文档版本**：v2.0  
> **编制视角**：AI 产品经理  
> **产品名称**：CaseAutoGenSystem — AutoGen 教学案例自动生成系统  
> **目标用户**：高校教师、培训师、教研人员  
> **技术核心**：Microsoft AutoGen 多智能体协作生成

---

## 1. 产品概述

### 1.1 产品定位

CaseAutoGenSystem 是面向**教学场景**的 AI 案例生成平台。教师配置课程与教学目标后，系统通过 **AutoGen 多 Agent 协作**（策划、学科专家、教学设计、撰写、评审）自动产出**结构化教学案例包**，用于课堂讨论、案例教学、翻转课堂等。

**不是**：论文写作工具、作业代写、文献综述生成器。

### 1.2 核心价值

| 痛点 | 价值 |
|------|------|
| 案例开发周期长 | 20 分钟内获得可授课初稿 |
| 缺乏案例设计方法论 | Pedagogy Agent 内置讨论题与活动设计 |
| 跨学科案例难产出 | Domain Expert Agent 按学科生成情境 |
| 质量不稳定 | Reviewer Agent + Rubric 门禁 |
| 难以迭代 | 案例库版本管理 + 局部再生成 |

### 1.3 标准产出：教学案例四件套

| 产出模块 | 内容 | 用途 |
|----------|------|------|
| **案例正文** | 情境背景、事件发展、冲突与决策点 | 学生阅读材料 |
| **讨论题** | 分层问题（理解/分析/评价/创造） | 课堂研讨 |
| **教师参考** | 教学目标解读、讨论引导、参考答案要点 | 教师备课 |
| **教学目标对齐表** | 目标—案例环节—评价方式映射 | 教研与审核 |

可选扩展：PPT 授课要点、课堂活动方案、延伸阅读建议。

## 2. 用户分析

### 2.1 用户画像

**画像 A：经管类教师「陈老师」**
- 场景：管理学课程需每学期更新企业案例
- 痛点：真实案例搜集难、讨论题设计耗时
- 期望：输入「数字化转型决策」主题，获得可讨论的案例 + 教师手册

**画像 B：工科教师「李教授」**
- 场景：项目式教学需要工程情境案例
- 痛点：案例偏理论、学生不感兴趣
- 期望：案例有具体技术冲突与团队协作矛盾

### 2.2 用户旅程

```
登录 → 创建案例任务 → 配置参数 → 选择 Agent 编排模板
  → 触发 AutoGen 生成 → 查看 Agent 协作日志（可选）
  → 预览案例四件套 → 人工编辑 → 保存入库 → 导出授课包
```

## 3. AutoGen 多智能体产品设计

### 3.1 Agent 角色定义（核心）

| Agent | 职责 | 输入 | 输出 |
|-------|------|------|------|
| **UserProxy / TeacherProxy** | 代表教师发起任务、确认节点 | 教师表单参数 | 任务指令 |
| **CasePlanner** | 案例结构策划、教学目标对齐 | 参数 + 学科模板 | 案例大纲 JSON |
| **DomainExpert** | 学科知识、行业情境、专业术语 | 大纲 + 学科 | 情境素材与事实层 |
| **CaseWriter** | 撰写案例正文 | 大纲 + 情境素材 | 案例正文 Markdown |
| **PedagogyDesigner** | 讨论题、课堂活动、评价设计 | 正文 + 教学目标 | 讨论题 + 活动方案 |
| **Reviewer** | 质量评审、修订建议 | 完整案例包 | 评分 + 修改意见 |
| **Editor（可选）** | 根据评审意见修订 | 案例包 + 评审意见 | 修订版案例包 |

### 3.2 编排模式（产品可选项）

| 模式 | AutoGen 实现 | 适用场景 | MVP |
|------|-------------|----------|-----|
| **Sequential 流水线** | 各 Agent 顺序执行 | 稳定、成本低、易调试 | ✅ 默认 |
| **GroupChat 评审循环** | Reviewer 触发 Writer 修订 | 质量要求高 | ✅ Sprint 2 |
| **Human-in-the-loop** | 教师在大纲节点确认 | 教研严格场景 | Should |

### 3.3 Agent 协作流程图

```
教师参数
    │
    ▼
┌─────────────┐
│ CasePlanner │ → 案例大纲 + 目标对齐方案
└──────┬──────┘
       ▼
┌─────────────┐
│DomainExpert │ → 行业/学科情境素材
└──────┬──────┘
       ▼
┌─────────────┐
│ CaseWriter  │ → 案例正文
└──────┬──────┘
       ▼
┌─────────────┐
│PedagogyDesigner│ → 讨论题 + 活动
└──────┬──────┘
       ▼
┌─────────────┐
│  Reviewer   │ → 评分 ≥ 阈值？
└──────┬──────┘
       │ 否（≤2 轮）
       ▼
   CaseWriter / Editor 修订
       │ 是
       ▼
  结构化案例包 → 案例库 → 导出
```

## 4. 功能需求

### F01 案例任务配置

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 案例标题/主题 | 文本 | 是 | 如「某制造企业数字化转型决策」 |
| 学科分类 | 下拉 | 是 | 管理学、经济学、计算机、法学等 |
| 课程名称 | 文本 | 是 | 如「组织行为学」 |
| 适用对象 | 单选 | 是 | 本科/硕士/企业培训 |
| 案例类型 | 单选 | 是 | 决策型/分析型/情境模拟/问题诊断 |
| 难度 | 单选 | 是 | 初级/中级/高级 |
| 教学目标 | 列表 | 是 | 可多条（知识/能力/素养） |
| 课时建议 | 数字 | 否 | 默认 2 课时 |
| 字数范围 | 数字 | 是 | 案例正文 1500-5000 字 |
| 特殊要求 | 长文本 | 否 | 行业偏好、禁忌话题等 |
| Agent 编排模板 | 下拉 | 是 | 标准流水线 / 深度评审 |

**验收**：提交后 5 秒内创建任务并进入生成队列。

### F02 AutoGen 生成引擎

- 按选定编排加载 Agent 配置（YAML）
- 异步执行，支持任务取消
- 记录 Agent 对话日志（可开关，供教研调试）
- 单任务并发 Agent 受配置限制
- 生成失败自动重试（章节级/Agent 级）

**验收**：标准流水线完整产出四件套；日志可查看每 Agent 输入输出摘要。

### F03 案例预览与编辑

- 分 Tab 展示：正文 / 讨论题 / 教师参考 / 目标对齐
- 富文本/Markdown 编辑
- 「仅重跑 Pedagogy Agent」「仅重跑 Reviewer」等局部再生成
- 版本历史对比

### F04 教师工作台与统计看板

工作台（P03 `/dashboard`）顶部为**量化统计看板**，下方为案例列表，帮助教师直观掌握案例生成与使用情况。

#### 4.1 统计看板指标

| 指标 | 说明 | 计算方式 |
|------|------|----------|
| 案例总数 | 当前筛选范围内案例任务数 | `count(case_tasks)` |
| 已定稿 | 状态为 finalized 的数量 | 完成率 = 已定稿 / 总数 |
| 生成中 | Agent 协作进行中 | `status=running` |
| 平均 Rubric | 已定稿案例质量均分 | `avg(rubric_overall)` |
| 预估节省工时 | 量化效率价值 | 已定稿数 × 可配置系数（默认 8h/案例） |
| 导出次数 | Word + PDF 导出合计 | `count(exports)`，可拆格式 |
| 平均生成耗时 | 端到端生成分钟数 | 任务日志 P95 或均值 |
| 讨论题总数 | 已生成讨论题累计 | 聚合 `discussion_questions` |
| 局部 Agent 重跑 | 人机协同迭代次数 | 重跑 API 调用计数 |
| 剩余生成额度 | 账户可用次数 | `user.quota_remaining` |

#### 4.2 图表维度

| 图表 | 维度 | 用途 |
|------|------|------|
| 学科分布 | 各学科案例数量条形图 | 了解授课覆盖结构 |
| 案例状态 | 已定稿/生成中/待编辑/草稿占比 | 快速把握工作进度 |
| 生成趋势 | 近 6 月每月新建案例数 | 观察使用频率变化 |

#### 4.3 时间筛选

- 本月 / 本学期 / 全部（切换后 KPI 与图表联动刷新）
- 默认进入：本学期

#### 4.4 案例列表（看板下方）

- 我的案例列表（状态：生成中/待审/已定稿）
- 标签：学科、课程、难度
- 复制为新任务、删除、分享链接（可选）
- 按更新时间排序，显示 Rubric 分（如有）

**验收**：登录后 2 秒内展示看板；筛选切换后指标与图表同步更新；移动端 KPI 卡片自适应单列/三列。

### F05 导出

仅支持以下两种格式（**不支持** Markdown、JSON 等其他导出）：

| 格式 | 说明 |
|------|------|
| **Word (.docx)** | 授课包排版：封面、案例正文、讨论题、教师参考、目标对齐表、虚构情境声明 |
| **PDF (.pdf)** | 基于 Word 渲染或独立排版，适合打印与只读提交 |

- 导出前可预览排版效果
- 导出文件含虚构情境声明页脚

### F06 Agent 配置管理（管理员）

> **详细说明见** [`06-Agent配置说明.md`](06-Agent配置说明.md)

Agent 配置决定「谁干什么、怎么协作、用什么模型、如何质检」，分为四层：**全局层 → 角色层 → 编排层 → 学科层**。

#### 9.1 功能模块一览

| 模块 | 用来干嘛 |
|------|----------|
| Agent 角色配置 | 定义 Planner / Expert / Writer 等 7 个角色的 Prompt、模型、输出格式 |
| Prompt 版本管理 | 调优后可版本对比、激活、回滚，关联 Rubric 评测 |
| 编排模板管理 | 定义 Sequential / GroupChat 流水线；教师创建案例时选用 |
| LLM 模型分配 | 按 Agent 指定模型与 temperature，平衡质量与 Token 成本 |
| Tool 工具绑定 | 为 Agent 注册 schema 校验、Rubric 打分、学科模板等硬能力 |
| 学科插件包 | 按学科注入案例结构模板与术语，无需改代码 |
| 运行时参数 | max_round、重试次数、Reviewer 通过阈值、任务超时与 Token 预算 |
| 日志策略 | 控制 Agent 对话日志粒度（教研调试 vs 存储成本） |
| 试跑 / 预览 | 改 Prompt 后用样例参数单 Agent 试跑 |
| 局部 Agent 重跑 | 教师仅重跑 Pedagogy / Reviewer，无需全流程 |

#### 9.2 管理后台页面（P07 `/admin/agents`）

- Agent 列表：启用状态、当前激活版本
- Agent 编辑：system_message、llm_config、tools、output_schema、保存版本
- 编排模板：Agent 顺序、GroupChat 规则、超时与预算
- 学科插件：上传 / 预览学科模板包
- （可选）运行监控：各 Agent 耗时、Token、Rubric 按版本对比

#### 9.3 教师侧配置边界

教师**不能**改 Prompt 与模型，仅可：
- 选择编排模板（标准流水线 / 深度评审）
- 选择学科（触发学科插件）
- 在案例详情页触发局部 Agent 重跑
- 开关是否查看 Agent 协作日志

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 配置页 < 2s；单案例生成 ≤ 15 分钟（标准流水线） |
| 可靠性 | 任务成功率 ≥ 95%；Agent 异常可恢复 |
| 安全 | JWT 认证；案例数据隔离；API Key 环境变量 |
| 合规 | 虚构情境声明；禁止生成违法、歧视内容；内容过滤 |
| 可扩展 | 新增 Agent 不改核心编排接口 |
| 可观测 | Agent 耗时、Token、Rubric 分可追溯 |

## 9. KPI

| 指标 | MVP 目标 |
|------|----------|
| 任务完成率（配置→导出） | ≥ 85% |
| 教师满意度 | ≥ 4.0/5 |
| Rubric 综合分 | ≥ 80 |
| 平均生成时长 | ≤ 15 min |
| 案例直接可用率（少改即用） | ≥ 60% |

## 10. 竞品与差异化

| 对比 | 通用 AI 写作 | 案例库平台 | CaseAutoGenSystem |
|------|-------------|-----------|----------------|
| 定位 | 通用文本 | 存量案例检索 | **生成 + 教学结构** |
| 架构 | 单轮 LLM | 无 AI 生成 | **AutoGen 多 Agent** |
| 产出 | 自由文本 | PDF 案例 | **四件套 + 可编排** |
| 质量 | 不稳定 | 人工保证 | **Reviewer + Rubric** |
